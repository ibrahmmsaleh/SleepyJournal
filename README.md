# Sleepy Journal Application

A lightweight, user-friendly web application built with Python (Flask) to help you monitor, log, and analyze your daily sleep patterns to improve your overall sleep hygiene and well-being.
---

## 🌐 Live Demo

**Try the app right away—no installation required!**
🔗 **[Student Task Manager — Open Website](https://sleepy-journal.vercel.app/)**



---

## ✨ Key Features

- **Log Sleep Sessions:** Record your sleep start time, wake time, and sleep quality ratings effortlessly.
- **Sleep History Dashboard:** View a chronological list of all your recorded sleep logs.
- **Analytics & Insights:** Automatically calculate total sleep duration and track average sleep quality over time.
- **Responsive UI:** Clean, modern interface designed with a custom CSS layout suitable for both desktop and mobile devices.

## Prerequisites

Make sure you have Python installed on your system (Python 3.7 or higher recommended).

---

## ⚙️ Installation & Setup

1. **Clone or Download** this repository to your local machine and navigate into the project directory:
   ```bash
   cd sleep-tracker
   ```

2. **Install Flask** (if you haven't already):
   ```bash
   pip install flask
   ```

3. **Run the Application**:
   ```bash
   python app.py
   ```

4. **Access the App**:
   Open your web browser and go to:
   `http://127.0.0.1:5000`

---

## 📋 Usage Guide

1. Open the application in your browser.
2. Fill out the sleep log form with your bedtime, wake time, and perceived sleep quality.
3. Submit the form to save your entry.
4. Review your past sleep logs and statistics directly on the main dashboard.
